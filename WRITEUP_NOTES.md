## Motivation: points to cover
- Drought is usually shown as rainfall or reservoir levels; NDVI shows the effect on living vegetation.
- Satellite view covers every acre consistently for 25 years, across state lines.
- Question: where did vegetation brown during 2001–2025 droughts, and how fast did it recover?

## Design decisions made (and alternatives)
**Map of grid cells (main view)**
- Position on a map encodes location; color encodes value. Chosen because the question is "where".
- 0.25° cells (~25 km): fine enough to show valleys vs mountains, coarse enough for ~5k SVG paths and a small JSON file. Alternative considered: per-state choropleth (hides within-state patterns); raw 0.05° pixels (too big for the browser).
- Equal-area conic projection centered on the West so cell areas are comparable.

**Two measures (toggle)**
- "Change vs normal" (default): each cell minus its own 2001–2020 growing-season mean. Needed because a desert and a forest have totally different raw NDVI; raw color would just show geography.
- "Raw greenness": for context on what's forest, farm, desert.

**Color**
- Anomaly: diverging brown-to-teal (ColorBrewer BrBG) with a neutral midpoint at 0. Brown/green maps to dry/healthy vegetation intuitively; symmetric domain ±0.10 so equal colors = equal magnitude; clamped so outliers don't wash out the scale.
- Raw: sequential yellow-green (YlGn). Single-hue ramp for magnitude.
- Alternatives: red-blue (reads as temperature), rainbow (not perceptually ordered).

**State ranking bars**
- Position along a common axis is more accurate than reading color off a map, so bars give a precise comparison of state means. Sorted so the most-browned state is on top. Doubles as a click target for focusing.

**Timeline**
- Monthly anomaly with 12-month trailing average to remove noise and seasonality. Area split above/below zero colored green/brown to match the map.
- Shaded bands for known drought periods (2002, 2012–16 California, 2020–22) as annotation.
- When a state is focused, dashed line shows the whole West for comparison.

**Interactions (and why each beats a static plot)**
- Year slider + play: animates 25 years; a static small-multiples grid of 25 maps would be tiny.
- Brush on timeline: average the map over a drought period (e.g. 2020–2022) instead of a single year.
- Click a state (map or bar): dims others, switches timeline to that state.
- Tooltips: exact NDVI, normal, % change for each cell (details-on-demand).
- Measure toggle: raw vs anomaly.

## Data transformations (already shown on page in "Data & transformations")
- GIBS PNG pixel colors → NDVI via official colormap (values binned to colormap step).
- Clip to 11 states; Apr–Sep mean per year; 0.25° block average; majority-state assignment.
- Baseline 2001–2020; monthly anomaly per state vs same calendar month; 12-mo rolling mean.
